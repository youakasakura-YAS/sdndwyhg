# 桑多涅的五夜后宫
> 原神同人 FNAF 类恐怖生存游戏，基于 Pygame‑CE 开发。

## OOC致歉
本作品属于同人二创，因游戏玩法需要，部分角色的性格、行为、对话存在OOC（脱离原作人设）情况。
无意歪曲、篡改原作角色形象，一切剧情、行为均为同人游戏的虚构创作。

## 游戏介绍
《桑多涅的五夜后宫》是一款原神同人午夜生存游戏。
你将扮演桑多涅，需要监控各个房间，观察哥伦比娅等角色的动向，利用道具躲避它们，熬过一个个夜晚。
核心玩法参考FNAF：监控摄像头、消耗电量、防御来袭的角色，活到早上6点即可通关当夜。

## 运行环境
- Python 3.10+
- Pygame‑CE
